# Iter Bratislaviense

Консольная текстовая RPG-игра для изучения словацкого языка.

## Структура проекта

```
/workspace/
├── main.py              # Точка входа, запуск игры
├── game_engine.py       # GameEngine - управление игровым циклом
├── player.py            # Player - состояние игрока (XP, энергия, инвентарь)
├── location.py          # Location - локации, NPC, навигация
├── quest.py             # Quest, QuestManager - система заданий
├── word_database.py     # WordDatabase - база слов словацкого языка
├── utils.py             # Утилиты (ANSI-цвета, вывод)
└── save.json            # Файл сохранения (создаётся автоматически)
```

## Классы (ООП архитектура)

### GameEngine
Управляет основным циклом игры, обработкой ввода и сохранением состояния.

### Player
Хранит инвентарь, уровень знания языка (XP), энергию, текущее местоположение.

### Location
Содержит описание места, доступные направления, скрытые предметы и NPC.

### Quest / QuestManager
Логика заданий. Каждое задание требует перевода слова или выбора правильного грамматического окончания.

### WordDatabase
База данных слов (словарь Python), где ключ — слово на русском, значение — на словацком + подсказка.

## Локации

- Вход в Старый город (стартовая)
- Братиславский Град
- Внутри Братиславского Града
- Главная площадь Старого города
- Собор Святого Мартина
- Примациальный дворец
- Дунайская набережная
- Статуя Чумила
- Мост SNP (Новый мост)
- Петржалка

## Команды игры

**Движение:**
- `север`, `юг`, `восток`, `запад` — идти
- `осмотр` — описание локации

**Взаимодействие:**
- `говорить [имя]` — диалог с NPC
- `ответить [текст]` — ответ на вопрос задания
- `искать` — поиск предметов

**Задания:**
- `задания` — список доступных
- `начать [номер]` — начать задание

**Инвентарь и статус:**
- `инвентарь` — выученные слова
- `статус` — характеристики

**Система:**
- `сохранить` / `загрузить`
- `помощь` — справка
- `выход` — завершить игру
